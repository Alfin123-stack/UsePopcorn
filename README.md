## 📖 Overview
**UsePopcorn** is a lightweight React app that lets you:
- 🎬 Search movies using the **OMDb API**  
- ⭐ Rate movies you’ve watched  
- 💾 Save your favorite movies to a personal list  

It’s a simple but powerful movie companion app, perfect for practicing **React hooks, state management, and API fetching**.  

---

## ✨ Features
- 🔍 **Search movies** from [OMDb API](https://www.omdbapi.com/)  
- 📄 View detailed movie information  
- ⭐ **Give ratings** for movies you’ve watched  
- ❤️ Save movies to a **favorites list**  
- ⚡ Built with **React 18 + Create React App**  

---

## 🏗 Tech Stack
- **Frontend**: React 18, React DOM  
- **Styling**: CSS / custom components  
- **API**: OMDb API (`https://www.omdbapi.com/`)  
- **Testing**: React Testing Library, Jest DOM, User Event  
- **Performance**: Web Vitals

## ⚡ Getting Started

### ✅ Prerequisites
Make sure you have:
- Node.js `>= 16`
- npm or yarn
- An **OMDb API Key** → [Get it here](http://www.omdbapi.com/apikey.aspx) (free tier available)

Clone the repository and install dependencies:
